Things I've built

Home server

Infrastructure as code · private repo

A self-hosted media and file server that rebuilds itself from a Git repository. Every night it pulls the repo and applies it, so the whole machine can be reinstalled from scratch.

  • Ansible and Docker Compose, with pinned images and a dry-run mode
  • Secrets encrypted in Git with SOPS and age
  • Encrypted restic backups kept in three places, one off-site
  • Discord alerts, hardware watchdog and GPU video transcoding
  • Ansible
  • Docker
  • Linux
  • Bash
  • restic

Home Server Backup

Google Drive client · personal use

The Google OAuth client my home server uses, through rclone, to copy its encrypted backups to my own Google Drive. It can only see the files it created itself, and it isn't a public service.

  • Google Drive API
  • OAuth 2.0
  • rclone
