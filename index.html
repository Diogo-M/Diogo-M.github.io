Projects

Duck Garage

Android app · Flutter · In progress

An offline-first maintenance log for your vehicles: every service, part and fill-up, with photos and receipts. No account and no server: everything stays on the phone and works without signal.

  • Say or type a fill-up and the right form opens already filled in, read on the phone by Gemini Nano, with a rule-based parser as a fallback
  • Fuel consumption measured only between full tanks, so the figures are honest
  • Reminders, home-screen widgets, and English and Portuguese
  • Its own design system, with unit, widget, golden and on-device tests

Flutter · Dart · Riverpod · Drift (SQLite) · Gemini Nano · Kotlin

Home server

Infrastructure as code · private repo

A self-hosted media and file server that rebuilds itself from a Git repository. Every night it pulls the repo and applies it, so the whole machine can be reinstalled from scratch.

  1. pullthe repository
  2. decryptsecrets kept in Git with SOPS and age
  3. applyAnsible and Docker Compose, pinned images
  4. back uprestic, three copies, one off-site

Also: Discord alerts, a hardware watchdog and GPU video transcoding.

Ansible · Docker · Linux · Bash · restic

Home Server Backup

Google Drive client · personal use

The Google OAuth client my home server uses, through rclone, to copy its encrypted backups to my own Google Drive. It can only see the files it created itself, and it isn't a public service.

Google Drive API · OAuth 2.0 · rclone
