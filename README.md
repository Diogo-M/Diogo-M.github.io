# Diogo-M.github.io

Homepage and privacy policy for **Home Server Backup**, the personal Google Drive OAuth client that rclone uses to copy my home server's encrypted backups to my own Drive.

Google requires both pages before an OAuth app can be published, even one used by a single person.

- Home: https://diogo-m.github.io/
- Privacy policy: https://diogo-m.github.io/privacy.html
