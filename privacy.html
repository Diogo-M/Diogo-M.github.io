Home Server Backup

Privacy Policy

Last updated: 27 October 2026

Home Server Backup is a personal Google Drive client operated by Diogo Magalhães for personal use. It is not offered to anyone else.

What it accesses

The client requests the drive.file scope, so it can only see and change files it created itself. It cannot read any other file in the Google Drive. It uploads encrypted backup files from the operator's home server and deletes old copies of those same files.

What it collects and shares

Nothing. The client has no servers, analytics or tracking of its own. Google user data is never collected, sold, shared with third parties, or used for advertising or to train AI models. The only data involved stays in the operator's own Google Drive and on the operator's own computers.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
